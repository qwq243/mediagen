# PPT 生图前检查（v3）

本清单配合 ppt_workflow.py，不是靠勾选即可放行。

1. 读资料和相关经验，给可见计划；确认观众、目的、观看方式、PPT 时间预算和后续用途。
2. 展示本机参考和网页采集入口，汇总购物车；第一轮 stage1 只确认沟通与参考方向。
3. 基于材料提出完整方案：整套叙事、逐页职责、关系、时间、密度和视觉设计一起对齐；
   检查顺序、证据边界、已实现/规划及可讲完性，通常推荐三个有实质差异的方向。
4. stage2 确认完整方案；色卡与角色字体必须可预览。
   附加素材、人物、讲稿和动效要明确；人物默认不出现，讲稿默认需要，转场逐次问、默认不要。
   艺术字可用于 display；同角色统一不等于全片只允许一种字体。
5. 参考是风格/内容/证据哪一种需标注；用户可自行找网站和回传素材。
   参考中的数字、logo、人物、文字不得偷偷带入页面；证据图保留原图。
6. 当前内容通过独立审核；编译英文视觉指令＋原文逐字文字，检查禁用项是否冲突。
7. 当前提示词独立通过；确认生图预算与授权，先做封面和代表性内页，不一波流。
8. 实际样张视觉审核后用户确认；其他页使用已确认图像作风格锚点。
9. 已应用的内容、设计、素材或图像版本改变，相关回执/审计失效；不无故失效无关页。
   素材收集不改生产方案；待处理修订阻断继续生产。不得自动续签或把回退当成批准。

`check --target samples`：准备实际样张调用。
`check --target render`：准备其余页面调用。
`check --target export`：准备交付，含逐页/整套审计和默认讲稿核对。

预算、状态和 hash 以 prompt-pack.json 为准。初始化脚手架中 P01 的存在、模型可选、
HTTP 200、图片尺寸正确、空 QA 勾选表，都不能替代以上确认和视觉证据。
