# 图片型幻灯片提示词协议（v2）

默认英文视觉指令，图中文字保持用户原文语言（默认中文），不翻译成英文。
这是一种可验证的工作约定，不保证英文比中文更好；后续以实际评审与反馈调整。

`ppt_workflow.py compile` 将 canonical pack 编译为每页 txt 和 JSONL；只读/不收费。
当前 agent 为 layout_focus 和 visual_instructions 提供足够详细且不矛盾的视觉设计：

- 总体：画幅、使用场景、阅读距离、角色字号层级、可见文字密度。
- 设计：批准色卡、display/heading/body/numbers 字体角色、图标笔画、材质和安全边距。
- 语义：信息关系、阅读顺序、结论与证据权重、每页任务和焦点。
- 几何：区域、对齐、比例、留白、文字区域、图文权重，避免把所有页填成等大卡片。
- 素材：参考职责和上传授权、只借哪些元素、不可继承哪些文字/人物/证据。
- 文字：明确 EXACT VISIBLE TEXT、逐字、原语言、禁止额外口号和占位。
- 证据：原图保留、预留合成槽，不让图像模型重画统计图或截图。
- 编辑：只改变指定区域；保留其余字、配色、字体外观、素材及空间关系。

同角色字体的 family 名是指导，不是光栅模型确定性保证。通过真实样张检查字形、
笔画、数字、粗细、层级和页间外观，再把实际批准的图片送入后续 edit 作为风格参考。
允许有理由的封面艺术字，不全局禁宋/Kai/书法，也不以“多样化”让相同角色每页换字体。

禁止矛盾，例如：批准艺术宋体，却在 negative prompt 写 no serif/calligraphy；
选择无人物，却要求真实学生或馆员照片；高密度硬塞全文，却要求远距离一眼读完。
超密度先改信息结构、拆页或移入讲稿，不能只缩字。

模型调用使用 newapi_image.py，但 PPT 必须经受控 wrapper；普通图片调用不受 PPT 闸门限制。
失败不自动换模型、降质量、无限重试。verify 是尺寸/格式检查，不能写成视觉验收。
截图、证书、logo、测量数据图与人工上传素材的身份不得凭生成模型编造。
